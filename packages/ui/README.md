# @tempo/ui 0.1.0-dev.1

Private isolated staging library. Five controlled components and minimal UI-only support. Consume named exports from @tempo/ui/actions/button, fields/text, fields/number, fields/checkbox, fields/dropdown, overlays and theme.

Web output/declarations are built and tested. Native source entrypoints are provided for future verification, not certified support. Native gesture/icon peers must be supplied by a future approved consumer; browser overlay requires React DOM.

No app APIs, auth, routing, data service or broad field registry. See project README/source-provenance.json for original hashes, deliberate staging overlap, differences and deferred ownership transfer. This private package has no lifecycle scripts and is not published.

Focus/error decoration is consumer-owned through style. Optional typed searchStyle colours dropdown search; source defaults stay intact. Browser icons use original locked SimpleLineIcons font with included notices. Source comparison uses explicit UI-only platform ports, not the production shell.
